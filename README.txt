HOME REACH CARE WEBSITE
=======================
Files (all in ONE folder, nothing inside sub-folders):
  index.html, styles.css, script.js
  logo.jpg, chair.jpg, lamp.jpg, cups.jpg
  standalone-site.html  (backup: one file with the images built in)

PUTTING IT ON GITHUB (works from a phone)
1. Unzip the folder on your phone or computer.
2. On GitHub, create a new repository (e.g. home-reach-care). Set it to Public.
3. Tap "Add file" > "Upload files". Select ALL the files listed above at once (index.html, styles.css, script.js and the 4 .jpg images). Tap "Commit changes".
4. Go to Settings > Pages. Under "Branch" choose main and folder /(root), then Save.
5. Wait 1 to 2 minutes. Your site is at https://YOUR-USERNAME.github.io/home-reach-care/
6. Check the images: open https://YOUR-USERNAME.github.io/home-reach-care/logo.jpg  If you see the logo, the images are in the right place.

IF IMAGES STILL DON'T SHOW
- You are probably looking at the file on github.com. Always open the github.io address instead.
- Make sure the 4 .jpg files are in the same list as index.html on GitHub.
- File names are case-sensitive and must be lowercase.
- Quick fix: upload standalone-site.html and rename it to index.html. Its images are built in.
